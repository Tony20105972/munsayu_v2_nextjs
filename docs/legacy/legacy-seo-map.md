## 레거시에서 확인한 규칙

1. **title** — `/` 와 `/sub/*` 11개가 모두 `문해와 사유(초등독서논술학원)` 로 같다.
   그누보드 화면(`/bbs/*`)만 `<페이지 이름> | 접미사` 형식을 쓴다.
2. **description·og:description** — 모든 페이지가 **같은 문구 하나**를 쓴다.
   - description: `대치동 문사유 초등관. 초등 독서논술, 문해력·사고력 완성, 1:1 맞춤 글쓰기 클리닉 및 최신 시간표 안내. …`
   - og:description: `생각의 깊이를 더하는 대치동 초등 문해력·독서논술 전문 문사유. …`
3. **canonical** — 한 페이지에도 없다.
4. **og** — `og:title`·`og:description`·`og:image`(`/seo/img/link-image.png`)·`og:url` 만 있다.
   `og:site_name`·`og:locale`·`og:image:width/height/alt` 은 없다.
5. **robots 메타** — 어느 공개 페이지에도 없다. `/robots.txt` 는 `Disallow: /uAdmin/` 한 줄. (EV-0002)
6. **sitemap.xml** — 404. (EV-0004)

## 신규 구현이 다르게 가는 점과 근거

| 항목 | 레거시 | 신규 | 근거 |
|---|---|---|---|
| title | 11개 화면이 모두 같음 | 홈만 접미사, 나머지는 `<페이지 이름> \| 접미사` | ASM-095 — 같은 title 11개는 검색 결과에서 구분되지 않는다 |
| description | 전 페이지 1종 | 화면별로 다르게 | ASM-095 |
| canonical | 없음 | 모든 화면에 추가 | ASM-095 |
| og 확장 | 없음 | `site_name`·`locale`·이미지 크기·`alt` 추가 | ASM-095 |
| `/sub/Recruit` | robots 메타 없음 | `noindex, nofollow` | ASM-088 |
| `/robots.txt` | `/uAdmin/` 만 차단 | `/admin`·`/api`·`/uploads`·`/account` 추가 차단 | 신규 경로가 늘었다 |
