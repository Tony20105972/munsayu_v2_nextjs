# 레거시 폼 계약 — Phase 1 관찰

> 모든 관찰은 GET·화면 열람만으로 수행했다. 입력, 동의 체크, 로그인, 가입, 제출은 수행하지 않았다.

## FM-001 강좌 수강 예약

- 등급: `OBSERVED` — `EV-0006`
- 진입: `/sub/schedule.n`의 **수강예약** 버튼. 대표로 대치본원 강좌 하나의 모달을 관찰했다.
- 화면상 선택 강좌 정보: 지점, 강좌명, 강의시간, 개강일.
- 필드: 학생 이름(placeholder `실명을 입력하세요`), 학부모 연락처(`010-0000-0000`), 재학 중인 초등학교명, 희망 수강 과정(초등 문해력·어휘·글쓰기·진단평가), 초등 학년(예비초~초6).
- 동의: 필수 체크박스. 목적은 좌석 배정 관리와 예약 확정 안내 문자 발송, 수집 항목은 이름·휴대폰 번호·학교/학년/수강과정, 보유기간은 해당 강좌 종강 및 정규 등록 안내 완료 시점 즉시 파기.
- 제출 버튼: `수강 예약 신청서 제출하기`. action/method와 서버 검증·제출 후 상태는 `UNKNOWN` (제출 금지).
- 관리자 연결: `AD-008` 강좌 수강 신청 목록, `AD-013` 개인정보 보존·파기. `EV-ADM-05`의 시간표/신청현황과 연결된다.

## FM-002 설명회 예약

- 등급: `OBSERVED` — `EV-0005`
- 진입: `/sub/Presentation`.
- 목록에서 지점별 설명회 일정과 `접수마감` 텍스트, 비활성화된 `접수마감` 버튼을 관찰했다. 대표 관찰 시점에는 접수 가능한 일정이 없어 예약 입력 폼을 열 수 없었다.
- 참석 인원 입력, action/method, 필드, 동의 문구, 서버의 정원·마감 전환은 `UNKNOWN`.
- 관리자 연결: `AD-003`~`AD-005`; 예약 건수와 참석 인원 분리는 `EV-ADM-03`의 사용자 제공 관리자 화면에서 관찰됐다.

## FM-003 공개 회원 로그인·가입

- 등급: `OBSERVED` — `EV-0007`
- 로그인 `/bbs/login.php`: 아이디·비밀번호 입력란, 로그인 상태 유지 체크박스, 아이디/비밀번호 찾기 링크(`/bbs/password_lost.php`). action/method와 인증 결과는 `UNKNOWN`.
- 가입 `/bbs/register.php`: 약관·개인정보 수집이용 동의 후 다음 단계. 공개 약관에는 아이디·이름·비밀번호 및 이메일·휴대전화번호를 회원 탈퇴 시까지 보유한다고 표시한다. 다음 단계의 실제 가입 필드는 미관찰(동의·다음 클릭 금지).
- 관리자 연결: `AD-002`; 공개 회원 제도의 유지 여부는 `Q-ADM-01` 답변 필요.
