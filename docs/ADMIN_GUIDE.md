# 문해와 사유 홈페이지 — 직원용 사용 설명서

> 홈페이지 관리자 화면을 쓰는 분을 위한 안내입니다. 컴퓨터를 잘 모르셔도 따라 할 수
> 있도록 적었습니다. 모르는 것이 나오면 그대로 두고 담당자에게 물어보셔도 됩니다.

---

## 1. 관리자 화면에 들어가기

1. 주소창에 홈페이지 주소를 넣고 뒤에 `/admin` 을 붙입니다. (예: `munsayu.com/admin`)
2. 관리자 아이디와 비밀번호를 넣습니다.
3. 위쪽에 메뉴 줄이 보입니다. 사진 작업은 **「이미지 관리」** 에서 합니다.

> 비밀번호는 다른 사람과 같이 쓰지 마세요. 사람마다 계정을 따로 만들 수 있습니다
> (「회원 관리」 → 관리자 계정 추가).

---

## 2. 사진 올리기

**「이미지 관리」 → 「이미지 보관함」 → 「사진 올리기」**

1. **사진 파일** 칸의 「파일 선택」을 누르고 올릴 사진을 고릅니다.
2. **대체 텍스트** 칸에 사진 설명을 한 문장 적습니다. (3장 참고)
3. 「사진 올리기」를 누릅니다.
4. 「사진을 올렸습니다」가 보이면 끝입니다. 아래 목록에 새 사진이 나옵니다.

### 올릴 수 있는 사진

| 되는 것             | 안 되는 것        |
| ------------------- | ----------------- |
| JPG, PNG, WebP, GIF | 그 밖의 모든 파일 |
| 한 장에 20MB까지    | SVG 그림 파일     |

### 올리면 자동으로 해 주는 일

- 사진이 너무 크면 **긴 쪽을 2000픽셀로 줄여** 저장합니다. 홈페이지가 느려지지 않게 하려는 것입니다.
- **촬영 위치 정보(GPS)를 지웁니다.** 휴대폰으로 찍은 사진에는 어디서 찍었는지가 숨어
  있을 수 있어서, 올릴 때 지웁니다.
- 세워서 찍은 사진이 눕지 않도록 **방향을 바로잡습니다.**

> 원본 파일은 보관하지 않습니다. 원본이 필요하면 직원 컴퓨터에 따로 두세요.

---

## 3. 대체 텍스트 쓰는 법

대체 텍스트는 **사진을 볼 수 없는 분께 읽어 주는 설명**입니다.
눈이 불편한 분이 쓰는 프로그램이 이 글을 소리로 읽어 줍니다. 검색에도 도움이 됩니다.

### 좋은 예

| 사진               | 대체 텍스트                                  |
| ------------------ | -------------------------------------------- |
| 대치본원 교실 사진 | `대치본원 2층 교실. 개별 책상이 줄지어 있다` |
| 김○○ 선생님 사진   | `김○○ 선생님 사진`                           |
| 북카페 사진        | `분당점 북카페. 책장과 읽는 자리`            |

### 피할 것

- `사진`, `이미지`, `IMG_1234` — 무엇인지 알 수 없습니다.
- `사진입니다` — "사진"이라는 말은 읽는 프로그램이 이미 알려 줍니다.
- 학생·학부모의 **이름이나 연락처는 절대 넣지 마세요.**

> 사진에 학생 얼굴이 들어 있으면 보호자 동의를 먼저 받으세요.

---

## 4. 휴대폰 사진 올리는 법

### 안드로이드 휴대폰

보통 JPG 로 저장되므로 **그대로 올리면 됩니다.**

### 아이폰

아이폰은 기본 설정에서 사진을 **HEIC** 라는 형식으로 저장합니다. 이 형식은 올릴 수
없다는 안내가 나옵니다. 아래처럼 설정을 한 번만 바꾸면 그다음부터는 그냥 올릴 수 있습니다.

1. 아이폰에서 **설정**을 엽니다.
2. **카메라** → **포맷**을 누릅니다.
3. **「높은 호환성」** 을 고릅니다.

이렇게 바꾸면 그 뒤에 찍는 사진은 JPG 로 저장됩니다.
**이미 찍어 둔 사진**은 이 방법으로 바꿀 수 있습니다.

- 사진 앱에서 사진을 열고 → 공유 버튼 → **「메일」** 이나 **「카카오톡」** 으로
  자기 자신에게 보냈다가 받은 사진을 내려받으면 JPG 가 됩니다.
- 또는 사진을 열고 → 편집 → 아무것도 바꾸지 않고 저장해도 형식이 바뀌는 경우가 있습니다.

> 잘 안 되면 사진을 담당자에게 보내 주세요.

## 5. 사진 바꾸기 (교체)

사진은 **먼저 올린 뒤, 쓰는 화면에서 골라** 바꿉니다.

### 강사 사진

**「강사 관리」** → 바꿀 강사 줄의 **「수정」** → **「강사 사진」** 에서 올린 사진을
고르고 **「강사 저장」**.

- 사진을 빼려면 「사진 없음(기본 이미지)」을 고릅니다. 기본 이미지가 들어갑니다.

### 메인 배너 (홈 맨 위 큰 사진)

**「이미지 관리」 → 「메인 배너」**

- 배너마다 **배경 사진 · 작은 윗글 · 제목 · 설명 · 버튼 2개 · 순서 · 보임 여부**를 정합니다.
- 숫자가 작은 배너가 먼저 보이고, 홈에서 번갈아 바뀝니다.
- 버튼은 **문구와 주소를 둘 다** 적어야 나옵니다.
- 잠시 내리고 싶으면 지우지 말고 **「홈에 보이기」를 끄세요.**

### 시설안내 사진

**「이미지 관리」 → 「시설안내 사진」**

- 지점(대치본원·분당점)마다 사진을 추가·삭제하고 **순서**와 **설명**을 고칩니다.
- 설명을 비워 두면 장식용 사진으로 봅니다(지금 홈페이지와 같습니다).

### 공지 본문에 사진 넣기

**「공지사항」** → 글 편집기 위의 **「이미지」** 단추 → 사진 선택 → 사진 설명 입력.
보관함에 올리는 것과 같은 검사를 거칩니다.

## 6. 사진 설명 고치기 · 사진 지우기

**「이미지 관리」 → 「이미지 보관함」** 목록에서

- **설명 고치기:** 「대체 텍스트」 칸을 고치고 **「설명 저장」**. 홈페이지에 바로 반영됩니다.
- **지우기:** 「사진 지우기」 → 확인.

> **화면에서 쓰는 중인 사진은 지울 수 없습니다.**
> 「쓰는 곳」 칸에 어디에 쓰는지 나옵니다. 그 화면으로 가서 사진을 바꾸거나 뺀 뒤에
> 지워 주세요. 실수로 홈페이지 사진이 사라지는 것을 막기 위한 장치입니다.

### 이미지 삭제 · 숨기기

- **여러 장 한 번에:** 왼쪽 상자로 사진을 고르고 **「선택 삭제」** → 확인.
  한 번에 50장까지 됩니다. 고른 사진 중 쓰는 중인 사진과 기존 사이트 사진은 지우지 않고
  그대로 두며, **지운 수와 남긴 이유를 끝나고 알려 드립니다.**
- **올리신 사진:** 목록에서 지우면 저장된 파일까지 함께 사라집니다. 되돌릴 수 없습니다.
- **기존 사이트 사진:** 홈페이지와 함께 올려 둔 파일이라 **지울 수 없습니다.**
  대신 **「숨기기」** 를 누르면 목록과 사진 고르기에서 빠져 더 이상 고를 수 없게 됩니다.
  다시 쓰려면 「보기 조건」에서 **「숨긴 사진만」** 을 고른 뒤 **「다시 보이기」** 를 누르세요.
- **쓰는 중인 사진은 숨기기도 막습니다.** 홈페이지는 그 사진을 계속 쓰는데 보관함에서
  사라지면 되돌릴 자리를 찾을 수 없기 때문입니다.
- 지운 일·숨긴 일·다시 보이게 한 일은 **누가 언제 했는지 기록에 남습니다.**

### 「교체 권장」 표시는 무엇인가요?

기존 홈페이지에서 가져온 사진 중 **학원 사진이 아닌 것으로 보이는 사진**입니다
(인터넷 무료 사진으로 추정). 학원에서 직접 찍은 사진으로 바꾸시는 것을 권합니다.
급한 것은 아니고, 당장 문제가 되는 것도 아닙니다.

### 「기존 사이트 사진 등록」 단추

지금 홈페이지가 쓰고 있는 사진을 보관함 목록에 올립니다. 이미 등록된 사진은 그대로
둡니다. **여러 번 눌러도 사진이 늘어나지 않습니다.**

---

## 7. 사진 용량 상한 바꾸기

**「사이트 설정」 → 「사진 한 장의 용량 상한」**

기본은 20MB 입니다. 바꿀 일은 거의 없습니다. 저장할 때 크기를 줄이므로 실제로 쌓이는
파일은 훨씬 작습니다.

---

## 8. 자주 나오는 안내 문구

| 문구                                            | 뜻과 할 일                                                                  |
| ----------------------------------------------- | --------------------------------------------------------------------------- |
| JPG, PNG, WebP, GIF 사진만 올릴 수 있습니다     | 사진이 아닌 파일이거나, 이름만 사진인 파일입니다. 다른 사진으로 올려 주세요 |
| SVG 그림 파일은 올릴 수 없습니다                | 안전 때문에 받지 않습니다. JPG 나 PNG 로 바꿔 주세요                        |
| 아이폰 사진은 JPG로 바꿔서 올려 주세요          | 4장을 보세요                                                                |
| 사진은 20MB 이하여야 합니다                     | 사진이 너무 큽니다. 휴대폰에서 크기를 줄여 보내거나 담당자에게 문의하세요   |
| 대체 텍스트를 적어 주세요                       | 사진 설명을 비워 두었습니다. 3장을 보세요                                   |
| 이 사진은 화면에서 쓰는 중이라 지울 수 없습니다 | 6장을 보세요                                                                |
| 이 사진은 화면에서 쓰는 중이라 숨길 수 없습니다 | 6장을 보세요                                                                |
| 기존 사이트 사진은 지울 수 없습니다             | 「숨기기」를 누르면 목록과 사진 고르기에서 빠집니다. 6장을 보세요           |
| 숨긴 사진은 화면에 붙일 수 없습니다             | 「보기 조건 → 숨긴 사진만」에서 「다시 보이기」를 먼저 누르세요             |

---

## 9. 기억해 주실 것

- 사진을 **올리고 · 바꾸고 · 지운 일**은 누가 언제 했는지 기록에 남습니다.
  잘못 만지는 것을 되돌리기 위한 기록이고, 감시하려는 것이 아닙니다.
- 신청자 개인정보(이름·연락처)를 보는 것도 기록에 남습니다. 업무에 필요한 만큼만 보세요.
- 사진에 **학생 얼굴이나 이름표, 연락처가 찍혀 있지 않은지** 올리기 전에 확인해 주세요.
