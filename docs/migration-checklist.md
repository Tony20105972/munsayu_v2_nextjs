### 1-3. DNS TTL 미리 줄이기 — `도메인관리자`

- [ ] 전환 **최소 48시간 전**에 munsayu.com 의 A·CNAME 레코드 TTL 을 **300초(5분)** 로 줄인다.

### 1-4. 메일 업체 결정과 SPF·DKIM — `원장님`·`개발` (D4, D7)

새 사이트가 메일을 보내는 경우는 **회원 비밀번호 재설정 한 가지**뿐입니다. 문자는 보내지 않습니다.

- [ ] 메일 업체를 정한다. 코드는 이미 두 가지를 지원한다 (ASM-010).
      - `console` — 메일을 **보내지 않고** 서버 기록에만 남긴다. 비밀번호 재설정이 동작하지 않는다.
      - `resend` — 실제로 보낸다. `RESEND_API_KEY` 가 필요하다.
- [ ] 추천: **resend**. 회원 기능을 유지하기로 했으므로(Q-ADM-01) 재설정 메일이 나가야 한다.
- [ ] 발신 주소를 정한다 (`MAIL_FROM`). 예: `no-reply@munsayu.com`
- [ ] **SPF** — munsayu.com 의 TXT 레코드에 메일 업체가 알려 준 발신 서버를 더한다.
      이미 SPF 레코드가 있으면 **새로 만들지 않고 기존 줄에 더한다.** SPF 는 도메인당 한 줄만 유효하다.
- [ ] **DKIM** — 업체가 준 CNAME(또는 TXT) 레코드를 그대로 넣는다.
- [ ] 넣은 뒤 업체 화면에서 "확인됨(verified)" 으로 바뀌는지 본다. 보통 몇 분~몇 시간.
- [ ] 테스트: 스테이징에서 비밀번호 찾기를 한 번 해 보고 **스팸함이 아닌 받은메일함**에 오는지 본다.
- [ ] `UNKNOWN` — munsayu.com 으로 지금 **학원이 받는 메일**이 있으면 MX 레코드는 **건드리지 않는다.**
      전환은 웹(A/CNAME)만 바꾼다. 메일 수신이 끊기면 큰 사고다. 현재 MX 설정을 미리 적어 둔다.

### 1-5. 운영 관리자 계정 만들기 — `개발`·`원장님`

- [ ] 운영 데이터베이스에 관리자 **1명**을 만든다.
      `BOOTSTRAP_ADMIN_ID=<아이디> BOOTSTRAP_ADMIN_EMAIL=<메일> npm run bootstrap:admin`
- [ ] 임시 비밀번호는 **터미널에 한 번만** 나온다. 바로 원장님께 전달하고 화면에서 지운다.
- [ ] 원장님이 로그인한 뒤 **비밀번호를 바꾼다.**
- [ ] 두 번째 직원 계정부터는 `/admin/members` 화면에서 원장님이 직접 추가한다 (D5).
- [ ] 스테이징에서 쓴 계정·비밀번호는 운영에서 **쓰지 않는다.**

### 1-6. 전환 일정 정하기 — `원장님` (D8)

- [ ] 날짜·시간을 정한다. 지켜야 하는 조건:
      - **설명회 시즌을 피한다.** 설명회 접수가 열려 있는 기간에는 하지 않는다.
      - **수강 신청이 몰리는 기간을 피한다.** (학기 시작 직전 2주)
      - **평일 오전**을 권한다. 문의 전화를 받을 수 있고, 문제가 생기면 당일에 되돌릴 수 있다.
      - **금요일 오후·주말·공휴일 전날은 피한다.** 문제가 생기면 며칠 방치된다.
- [ ] 정한 일정: ____년 __월 __일 __시 (담당자 전원이 2시간 비어 있을 것)
- [ ] 되돌리기 판단 시각을 미리 정한다 (보통 전환 +2시간). `docs/rollback-plan.md` 2장.

### 1-8. 운영에서 이미지 다시 올리기 — `직원` (D1, AD-015)

저장소도 스테이징과 운영이 다를 수 있어, 운영에서 **한 번 더 올려야** 합니다.

- [ ] 올릴 사진을 미리 모아 둔다. 올리는 자리와 방법은 `docs/ADMIN_GUIDE.md` 2·5장.
- [ ] 순서대로 올린다: 홈 배너 → 시설 사진(대치·분당) → 강사 사진 → 공지 본문 사진
- [ ] 사진마다 **대체 텍스트**를 적는다. 비어 있으면 보관함에 들어가지 않는다.
- [ ] 다 올린 뒤 공개 화면을 휴대폰으로 한 번 훑어 깨진 사진이 없는지 본다.
- [ ] 코드에 들어 있는 레거시 사진 57개는 다시 올릴 필요가 없다 (저장소가 아니라 코드에 있다).
