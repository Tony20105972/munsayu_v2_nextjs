# 가정(ASM) 및 원장님께 물을 질문

| 번호 | 무엇을 가정했나 | 왜 | 어디에 반영했나(파일·설정 키) | 바꾸는 방법 | 원장님께 물을 질문(쉬운 말) |
|---|---|---|---|---|---|
| ASM-001 | 설명회 상태는 `접수중`·`마감임박`·`접수마감`이고 관리자가 직접 바꾼다. 정원은 막지 않으며 1건 최대 2명이고 의도적 재신청은 허용한다. | 사용자 변경 지시 2026-11-11 | `prisma/schema.prisma`, `docs/contracts/architecture.md` | 관리자 상태 목록·최대 인원 설정을 수정 | 설명회에 꼭 필요한 다른 상태나, 한 예약에 3명 이상이 필요한 경우가 있나요? |
| ASM-010 | 계정 찾기 메일은 기본 console 어댑터를 쓰고 Resend는 환경 변수로 선택한다. | 업체 미정, 실제 발송 금지 | `src/server/adapters/mail`, `MAIL_ADAPTER` | 환경 변수와 어댑터 구현 교체 | 메일 업체를 정하시면 알려주세요. |
| ASM-011 | 레거시 폰트는 라이선스 확인 전 오픈 라이선스 대체 폰트를 쓴다. | 이미지 권리만 확정됨 | `app/layout.tsx` 폰트 설정 | 라이선스 확인된 폰트로 교체 | 현재 쓰는 글꼴의 사용 권한을 확인할 수 있나요? |
| ASM-002 | 회원은 가입·로그인 유지·찾기·수정·탈퇴를 하고 신청은 비회원도 가능하다. | 사용자 확정 답변 | `User`, `AuthSession`, `Membership` 계약 | 인증 서비스와 화면에서 기능 단위로 켜고 끔 | 회원에게 추가로 꼭 필요한 기능이 있나요? |
| ASM-003 | 강사 한 명은 여러 팀에 소속될 수 있고 팀별 노출 순서를 둔다. | 같은 강사가 팀별로 중복 등록됨(EV-ADM-04) | `Instructor`, `InstructorTeamMembership` | 팀 소속 레코드를 관리자에서 조정 | 지점마다 사진이나 약력을 다르게 보여야 하나요? |
| ASM-004 | 자체 접속자 집계는 만들지 않고 분석 ID 환경 변수만 둔다. | 기존 집계가 유효 방문자 정보를 남기지 못함(EV-ADM-06/07), 사용자 기본안 | `ANALYTICS_PROVIDER_ID` | 분석 도구 어댑터·환경 변수 교체 | 어떤 방문 통계 도구를 쓰고 싶으신가요? |
| ASM-005 | 설명회 관리 코드는 자동 생성하되 관리자가 고칠 수 있다. | 형식이 일정하지 않음(EV-ADM-03) | `Event.managementCode` | 관리자 편집 화면에서 수정 | 지금 관리코드에 꼭 지켜야 하는 규칙이 있나요? |
| ASM-006 | CSV는 신청 목록에서 현재 필터 결과의 전체 항목을 내보내며 기록한다. | 사용자 기본안 | `AuditLog`, `/api/admin/applications/export` | 허용 열·필터를 관리자 정책으로 조정 | 엑셀에서 꼭 필요한 열이 더 있나요? |
| ASM-007 | 문자신청내역·강사지원은 공개 신청 화면 증거가 없으므로 이번 이관 범위에서 제외한다. 첨부가 확인되면 검증 업로드·저장소 어댑터로 설계한다. | Phase 1에 공개 계약 없음 | `migration-matrix.md` | 증거 또는 화면을 받으면 기능 계약 추가 | 문자신청과 강사지원 화면(개인정보는 가린 것)을 보여주실 수 있나요? |
| ASM-008 | Vercel을 전제로 하되 DB·이미지 저장소는 어댑터로 분리하고 로컬은 Docker PostgreSQL을 쓴다. | 사용자 기본안 | `StorageAdapter`, `DATABASE_URL` | 배포 설정에서 어댑터 구현 교체 | 이미 사용 중인 DB나 파일 저장소가 있나요? |
| ASM-009 | 설명회 개인정보도 레거시 강좌 동의 문구와 같은 기본 보존 기준을 쓰고, 종료·안내 완료 시 관리자가 파기 대상 시각을 설정한다. | 설명회 레거시 동의 문구는 미관찰; 단일 설정값 원칙 적용 | `PrivacyRetentionSetting`, 신청·예약 `purgeEligibleAt` | 관리자 설정 또는 보존 기준을 수정 | 설명회 신청 정보는 행사가 끝난 뒤 얼마나 보관하면 될까요? |
