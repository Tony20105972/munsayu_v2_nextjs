## 4. 의도된 변경 — 근거가 있는 것 (7건)

| 항목 | 레거시 | 신규 | 근거 |
|---|---|---|---|
| 화면별 title·description·canonical | 전 화면 동일, canonical 없음 | 화면마다 다르게 + canonical | ASM-095 (신규) |
| 홈 히어로 제목 단계 | `h2` | `h1` | ASM-046 |
| 제목 단계 정리 | `h4`·`h5`·`h6` 혼용 | `h2`·`h3` 로 정돈 | 보조기기 읽기 순서 |
| 오시는 길 지도 | iframe 삽입 | 링크만 | ASM-050 |
| 설명회 신청 항목 | `wr_school`·`department` 포함, 참석 3명 이상 | 신규 설계, 최대 2명 | D9 / ADR-004 |
| 공지 목록 검색 | 있음 | 없음 | ASM-054 |
| `/sub/Recruit` 색인 | 제한 없음 | `noindex, nofollow` + 메뉴 숨김 | ASM-088 |

모바일(390)에서 레거시는 문서 너비가 **780px 로 넘쳐 가로 스크롤**이 생긴다. 신규는
390 에 맞춘다. 그래서 390 화면은 1:1 픽셀 비교가 성립하지 않는다.

## 6. 데이터 차이 — 비교 대상이 아닌 것

신규는 가짜 시드 자료로 띄웠기 때문에 아래는 화면 결함이 아니다. (CLAUDE.md 4장)

- 강사 카드 수 — 레거시 14명 / 시드 3명(`가상강사A·B·C`)
- 시간표 강좌 목록 — 레거시 실제 강좌 / 시드 샘플
- 설명회 목록 — 레거시 개원 기념 설명회 10건(전부 마감) / 시드 샘플
- 공지 목록 — 레거시 실제 공지 / 시드 3건

레거시 강사 실명은 직원 개인정보라 증거 파일에 가려서 적었고 원본 HTML 은 커밋하지 않았다.
