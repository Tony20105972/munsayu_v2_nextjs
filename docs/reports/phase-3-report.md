- 관리자 화면 `AD-001`~`AD-008`, `AD-012`, `AD-013`. `app/admin/login`은 가드 밖, `app/admin/(authed)/**`는 가드 안이다.
- 레거시 URL 호환을 `proxy.ts` 한 곳에 모았다. 308 5건, 410 2건(`/uAdmin/**`, `/adm/**`), 유지 11건, 외부 링크 1건.
- 페이지 19곳에 `title`·`description`·`canonical`·OG 메타데이터를 넣었다. 관찰된 레거시 title 4건은 원문 그대로 쓴다.
- Next.js 16의 `middleware.ts` 지원 종료에 맞춰 `proxy.ts`로 옮겼다.
- 스텁을 모두 실제 구현으로 교체했다(`grep -rn "STUB" app src` → 0건).

## 사용자 결정이 필요한 항목

1. 시설안내·학원소개 사진이 무료 사진(Unsplash)이다. 실제 학원 시설 사진으로 바꿀지 (`ASM-016`).
2. `석혜선 선생님 사진`과 `문해와 사유 사진`이 레거시에서 **같은 파일**이다. 자리표시로 보이는데 실제 사진이 필요한지.
3. 폰트 사용 권한 확인 (`ASM-011`).
4. 방문 통계 도구 선택 (`ASM-004`, `ASM-077` — 현재 GA4 형식 가정).
5. 공지 작성·수정 화면이 필요한지 (`ASM-015`).
