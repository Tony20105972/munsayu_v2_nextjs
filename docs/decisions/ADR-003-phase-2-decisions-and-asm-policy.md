# ADR-003 — Phase 2 확정 결정과 ASM 작업 규칙

- 상태: Accepted (사용자·원장 확인, 2026-11-11)
- 근거: 사용자 지시, EV-0006~0010, EV-ADM-01~07

## 결정

- D1: 원본 사진·서버 백업은 확보 불가이며 레거시 데이터는 이관하지 않는다.
- D2: 신규 PostgreSQL + Prisma를 사용한다.
- D4: 1차 문자 발송은 구현하지 않는다. 알림 인터페이스와 개발·테스트 콘솔 어댑터만 둔다.
- D5: 단일 관리자 역할이며 관리자가 관리자 계정을 추가·삭제한다.
- AD-002 공개 회원가입·로그인과 AD-013 개인정보 조회·CSV 다운로드 기록을 이관한다.
- 개인정보 보존 기간은 관리자 설정이며, 기본값은 강좌 동의 문구의 "종강 및 정규 등록 안내 완료 시점 즉시 파기"(EV-0006)이다. 자동 파기는 기본 비활성이다.
- 설명회·강좌는 정원 숫자로 접수를 막지 않는다. 마감 상태 확인과 동일 연락처 중복 확인 및 저장은 하나의 트랜잭션이다.

## ASM 정책

Phase 안의 미확인 사항은 기본안을 적용하고 `docs/reports/open-questions.md`에 ASM으로 남긴다. 기본안은 관찰된 동작을 우선하며, 없으면 설정값 또는 관리자 설정으로 나중에 바꾸기 쉬운 방식을 택한다. [확정] BLUEPRINT 원칙이 우선한다.

## 결과

Phase 2 Gate의 운영자 확인 항목은 위 결정 또는 해당 ASM으로 판정한다. 다음 Phase는 여전히 사람 승인 뒤에만 시작한다.
