# ADR-007 — Phase 5 관리자 범위 변경 (AD-009 · AD-011 · AD-014)

- 상태: 확정
- 날짜: 2026-11-12
- 결정한 사람: 사용자 (2026-11-12 지시 및 같은 날 후속 수정)
- 관련 근거: EV-ADM-08 ~ EV-ADM-11 (사용자 제공 가림 화면), EV-0013 (`/sub/abouttch3`), EV-0014 (`/sub/Recruit`)

## 배경

Phase 2에서 아래와 같이 정했었다.

- `AD-009` 입학진단: 외부 Google Forms 링크만 유지, 구현 없음
- `AD-010`·`AD-011`: 공개 계약 증거가 없어 범위 제외 (ASM-007)
- 관리자 공지 작성: 범위 밖 (ASM-015, 공개 읽기 전용)

2026-11-12에 사용자가 관리자 화면 4장을 추가로 제공하면서(EV-ADM-08~11) 범위를 바꿨다.
Phase 5에서 `/sub/abouttch3`와 `/sub/Recruit`를 GET 으로만 다시 관찰해 근거를 보강했다.

## 결정

### AD-009 입학진단 및 상담 신청 — 관리 화면만 이관

- 공개 화면에는 **신청 폼을 두지 않는다.** 「문해력 진단 신청」 버튼은 관리자가 등록한
  구글 폼 주소를 연다. 주소는 `AppSetting`의 `diagnosis.cta.externalUrl` 에 둔다. // ASM-082
- 관리자 화면(`/admin/consultations`)은 EV-ADM-08 구성대로 만든다: 상태별 건수,
  학부모 성함·연락처 검색, 처리 상태 일괄 변경, 선택삭제, CSV(AD-013 기록).
- `POST /api/consultation-applications` 는 외부 신청을 관리자 목록으로 끌어올 때 쓰는
  입력 경로로 남긴다. 사이트 화면에서 부르지 않는다.

> **경과:** 처음에는 사이트 내 신청 폼까지 만들기로 했으나, 같은 날 사용자가
> "폼은 지우고 구글 폼 링크만 넣으면 되게 해 달라"고 수정했다. 신청 내역 표와 DB 표는
> 유지한다(사용자 선택). 사이트 내 폼이 없으므로 목록은 외부 연동이 붙기 전까지 비어 있다.

### AD-011 강사 지원 — 범위 포함 (ASM-007 수정)

- `/sub/Recruit` 를 레거시와 같은 주소에 만든다. 항목·선택지·버튼 문구는 EV-0014 관찰값 그대로다.
- 레거시처럼 **주 메뉴에 기본으로 보이지 않는다.** 관리자 설정으로 켠다. // ASM-088
- 제출 서류는 PDF·DOCX·HWP·HWPX 만 받고, 확장자가 아니라 **파일 내용**으로 형식을 확인한다. // ASM-085
- 서류는 StorageAdapter 의 **비공개 영역**에 저장하고 공개 주소를 만들지 않는다.
  관리자 인증 경로(`/api/admin/instructor-applications/document`)로만 내려받고,
  내려받기마다 `RESUME_DOWNLOAD` 기록을 남긴다. (AD-013)
- 보존 기간이 지나 파기하면 **파일도 함께 지운다.**

### AD-014 공지사항 관리 — 신규 기능 ID

- 그누보드 게시판 엔진(게시판·그룹·포인트·스킨·SNS·접속기기)은 옮기지 않는다.
  레거시 게시판이 `notice` 하나뿐이라 공지사항 단일 게시판으로 만든다. // ASM-089
- 관리자 CRUD, 상단 고정, 임시 저장/게시, 첨부파일, 본문 이미지 업로드를 넣는다.
- 본문 HTML 은 **저장 전과 조회 시** 모두 허용 목록으로 정리한다. 편집기와 정리기 선택은 ADR-006.
- 공개 목록·상세가 DB 의 글을 보여 준다. 한 쪽에 15건으로 레거시와 같다. (EV-0007)
- 레거시 글 번호(`wr_id`)를 저장해 `/bbs/board.php?bo_table=notice&wr_id=N` → `/notice/N`
  308 연결이 **가져온 글로 이어진다.** (RT-001)

### AD-010 설명회 알림 신청 — 범위 포함 (Phase 3·4 승인 시 결정)

- 홈 하단 폼을 되살린다. 항목은 레거시와 같고(학년·학생 이름·학교명·보호자 연락처),
  레거시에 없던 개인정보 동의와 알림 수신 동의를 **따로** 받는다. // ASM-086
- **문자 발송은 하지 않는다.** 신청 내역만 보관하고 직원이 직접 연락한다. (D4)

## 함께 바뀐 것

- `PrivacyRetentionSetting` 에 상담·강사 지원·알림 신청 보유기간 문구 칸을 추가했다.
  신청자가 본 문구와 저장되는 정책 버전이 종류마다 따로 간다. (BZ-002)
- 파기(`runPurge`)가 새 세 종류를 함께 처리하고, 강사 지원은 저장된 파일까지 지운다.
- 관리자 메뉴 순서를 레거시에 맞췄다: 회원관리 → 설명회관리 → 강사관리 → 시간표관리 →
  입학진단관리 → 문자신청내역 → 강사지원관리 → 공지사항.
- 새 의존성 `sanitize-html` 을 넣었다. 이유는 ADR-006.

## 되돌리는 방법

- AD-009 를 다시 "링크만"으로 좁히려면 `/admin/consultations` 화면과
  `ConsultationApplication` 표를 지우면 된다. 공개 화면은 이미 링크만 쓴다.
- AD-011 을 끄려면 관리자 설정에서 메뉴를 숨긴 채 두고 `/sub/Recruit` 라우트를 지운다.
  저장된 서류는 파기 절차로 함께 지워야 한다.
