# ADR-002: Phase 1 Gate의 관찰 가능 범위

- 상태: 승인됨 (사용자 지시, 2026-11-09)
- 맥락: 레거시에는 sitemap이 없고, 실제 제출은 운영 사이트 안전 규칙상 금지된다. 설명회 예약은 현재 모두 마감이라 입력 화면도 열리지 않는다.
- 결정: URL Gate는 sitemap 404 확인과 내부 링크 포화 추적으로 판정한다. 폼 Gate는 클라이언트 계약만 필수로 하며, 제출 없이는 알 수 없는 서버 규칙·닫힌 폼은 `UNKNOWN`과 운영자 답변/사용자 제공 화면으로 대체한다. 운영자 답변 수령은 Phase 2 시작 조건으로 이동한다. REA Gate는 동일 템플릿의 반복 페이지 전수가 아니라 주소 형식별 대표 페이지 전부를 검사하며, REA 오류는 오류 증거로 대체한다.
- 결과: 미관찰 서버 동작을 사실로 기록하지 않고, Phase 2에서 D9 등 계약 결정으로 명시한다.
