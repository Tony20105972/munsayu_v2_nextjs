# ADR-004 — 재신청·자산·계정 메일 정책

- 상태: Accepted (사용자 결정, 2026-11-11)
- 같은 연락처의 같은 강좌/설명회 재신청은 허용한다. 버튼 중복 클릭·재전송만 idempotency key로 막는다.
- 신청 저장은 마감 상태 확인과 저장을 하나의 트랜잭션으로 수행한다. 중복 검사용 잠금·유일 제약은 사용하지 않는다.
- 레거시 사이트 이미지는 학원 귀속으로 커밋 가능하다. 폰트는 별도 라이선스 확인 전 오픈 라이선스 대체 폰트를 사용한다.
- 문자는 발송하지 않는다. 계정 복구 메일은 MailAdapter로 제공하며 기본 선택은 console, Resend는 환경 변수로 선택 가능한 구현으로 둔다. 실제 메일을 발송하지 않는다.
